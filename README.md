# Bioinformatics Basics

My first steps in Python for bioinformatics (Weeks 1 and 2).

## What is inside
- hello.py, dna.py, strings.py: first Python code and DNA as text
- gc.py, valid.py: GC content and DNA validation
- loops.py, functions.py: loops, functions, reverse complement
- central_dogma.py: transcription and translation
- dna_toolkit.py: a small DNA toolkit (length, GC content, reverse complement, RNA, protein)
- lists.py, codon_count.py: lists, dictionaries and codon counting
- read_fasta.py, filter_fasta.py: reading and filtering FASTA files with Biopython
- fetch_gene.py, tp53_protein.py: fetching genes from NCBI and finding the protein

## How to run
pip install biopython
python dna_toolkit.py

## Learning log
Week 1: Python basics, GC content, loops, functions, DNA toolkit.
Week 2: lists, dictionaries, Linux commands, FASTA files, NCBI gene download.
