# bioinformatics-basics# Bioinformatics Basics

My first steps in Python for bioinformatics (Week 1).

## What is inside
- hello.py, dna.py, strings.py: first Python code and DNA as text
- gc.py, valid.py: GC content and DNA validation
- loops.py, functions.py: loops, functions, reverse complement
- central_dogma.py: transcription and translation
- dna_toolkit.py: a small DNA toolkit (length, GC content, reverse complement, RNA, protein)

## How to run
python dna_toolkit.py

## Learning log
Day 1: variables and strings. Day 2: GC content and if/else. Day 3: loops, functions, DNA toolkit.
